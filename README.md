# Information-Security-Management-System-Information-Security-Program-ISMS-ISP-
Information Security Management System (ISMS) project

An Information Security Management System (ISMS) developed for a fictional insurance provider Shameless Consulting Ltd.
Covers asset management, risk assessment, incident response, and policy development, mapped throughout to ISO 27001 and NIST frameworks.

## Contents
- `Information Security Management System - Shameless Consulting Ltd..pdf` — full ISMS/ISP documentation

## Overview
This project outlines a security governance framework including:
- Asset management
- Risk management with risk register
- Risk assessment methodology
- Incident response methodology
- Security policies and procedures
- Roles and responsibilities
- Regulatory mapping and compliance considerations
